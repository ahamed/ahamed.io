# Texture credits

Planet and sky textures by [Solar System Scope](https://www.solarsystemscope.com/textures/), licensed under
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

| File                      | Source map             |
| ------------------------- | ---------------------- |
| `2k_earth_daymap.ktx2`    | Earth day map (2K)     |
| `2k_earth_clouds.ktx2`    | Earth clouds (2K)      |
| `2k_moon.ktx2`            | Moon (2K)              |
| `2k_mars.ktx2`            | Mars (2K)              |
| `2k_stars_milky_way.ktx2` | Stars + Milky Way (2K) |

Each file is a KTX2 (Basis Universal) GPU-compressed encoding of the unmodified source map,
made by `pnpm textures`. Phobos, Deimos and the asteroids are generated in code.
